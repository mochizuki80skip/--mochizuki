# 接骨院 出店イベント 予約空き状況サイト

出店イベントの予約枠の空き状況（〇△×）をスプレッドシートで管理し、サイトで公開。
お客様は希望日時を**第2希望まで**選んで公式LINEに送信できる。

## 確定した仕様

- 開催は**複数日**
- 受付時間は **9:00 から 15分刻み**
- 空き状況は**先生数から自動算出**（1枠＝先生1人につきお客様1人）
- 表示：**〇** 空きあり ／ **△** 残りわずか（要問合せ）／ **×** 満員

## いまここ：スプレッドシートの骨子

`spreadsheet-setup.gs` が、そのまま動くスプレッドシートを生成する Google Apps Script。

### セットアップ手順

1. Google スプレッドシートを新規作成
2. **拡張機能 → Apps Script** を開く
3. `spreadsheet-setup.gs` の中身を丸ごと貼り付けて保存
4. スプレッドシートに戻ると **メニュー「▶ 予約シート」** が出る
   （出ない場合は一度リロード）
5. 「① 初期セットアップ」を実行（初回だけ権限の許可が必要）
6. 中身を入力 → 「② 空き枠を再生成」を実行

### できあがる4シート

| シート | 役割 | 入力するもの |
|---|---|---|
| **設定** | イベント全体の前提値 | 開催日リスト・受付時間・△閾値・LINE URL 等 |
| **先生マスタ** | スタッフ一覧 | 先生名・**新規対応可☑**・勤務日・勤務時間 |
| **空き状況** | サイトが読む表（自動計算） | 触らない（②で再生成） |
| **予約受付** | LINEから来た予約の台帳 | お名前・希望日時・確定枠・状態 |

### 「先生チェック→空き反映」の流れ

1. 「先生マスタ」で先生の **新規対応可** にチェック＋勤務時間を入力
2. 「空き状況」の **対応可能枠** が自動集計
   （`= その日・その時刻に勤務中で新規対応可な先生の人数`）
3. **残り枠 = 対応可能枠 − 予約済み**、**ステータス**(〇△×)も自動
4. 「予約受付」で確定枠を埋めると、その枠の残りが自動で減る

> チェックを入れる／外すだけで、サイトの空き状況が変わる設計。

## このあとの予定（サイト側）

1. スプレッドシートを**ウェブに公開**（または Apps Script の Web API / Sheets API で配信）
2. フロントが「空き状況」を読み、日付タブ × 時間グリッドで 〇△× を表示
3. お客様が第1・第2希望を**必須選択** → LINE送信用テキストを自動生成 → 公式LINEへ

※ 既存の `reserve/`（threease 連携版）とは別物。あちらは外部予約APIのミラー、
こちらは手動管理のイベント用。
