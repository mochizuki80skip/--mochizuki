# 接骨院 出店イベント 予約空き状況サイト

出店イベントの予約枠の空き状況（〇△×）を、院スタッフの予約ボード（スプレッドシート）
から自動集計してサイトに表示。お客様は希望日時を**第2希望まで**選んで公式LINEへ送れる。

## 確定仕様

- 開催は **複数日**（タブ＝開催日ごと）
- 施術は **1コマ30分**
- 空き状況は **先生（ベッド）数から自動算出**
  - 予約ボードのセルに **予約者名（1行目）/ 連絡先（2行目）** を入力＝その枠は埋まり
  - **新規対応 ☑** のベッドだけを新患向けの空きとして数える
  - 施術者が未割当のベッドは数えない
- 表示：**〇** 空きあり ／ **△** 残りわずか（要問合せ）／ **×** 満員

### 開催日ごとの設定

| 日付 | 営業時間 | サイト表示の刻み | 休憩 |
|---|---|---|---|
| 7/24 | 9:00〜12:00 / 14:00〜18:00 | 30分 | 12:00〜14:00 |
| 7/25 | 9:00〜12:00 / 14:00〜18:00 | 15分 | 12:00〜14:00 |
| 7/26(日) | 9:00〜17:00（通し） | 15分 | なし |

## 仕組み

```
【予約ボード】タブ=開催日   ← 院スタッフが使う作業表（今のまま運用OK）
  列 = ベッド（施術者・新規対応☑）
  行 = 時間（15分行 / 施術30分=2行）
  予約 = セルに予約者名+連絡先を入力
        ↓ availability-aggregator.gs が読み取り・集計
【サイト公開用】シート / doGet JSON   ← 個人情報なし・フラットな〇△×
        ↓
【サイト】日付タブ × 時間グリッドで〇△×表示 → 第1/第2希望を選んでLINE送信
```

個人情報（名前・連絡先・来院きっかけ）は公開用シートに出さないので、サイトに漏れない。

## ファイル

- **`availability-aggregator.gs`** … 予約ボードを読んで「サイト公開用」シートへ
  〇△× を書き出す Google Apps Script。Web アプリとして公開すれば JSON もサイトへ配信できる。
- **`index.html` / `style.css` / `app.js`** … お客様向けサイト本体。
  日付タブ × 時間グリッドで 〇△× を表示し、第1・第2希望を選んで LINE 送信する。

### 導入手順（集計GAS）

1. 予約ボードのスプレッドシートで **拡張機能 → Apps Script**
2. `availability-aggregator.gs` を貼り付けて保存
3. 先頭の `CONFIG` をイベントに合わせて調整（**タブ名はシート名と完全一致**させる）
4. シートを開き直して **メニュー「▶ 空き集計」→「いますぐ集計」** →「サイト公開用」シート生成
5. （任意）トリガーで `aggregateAvailability` を時間主導にすると自動更新

### サイトと連携（Web アプリ公開）

1. Apps Script エディタ右上 **デプロイ → 新しいデプロイ**
2. 種類「ウェブアプリ」、アクセスできるユーザー「**全員**」で発行
3. 発行された URL を `app.js` の `CONFIG.apiUrl` に貼り付け
4. `CONFIG.lineOaId`（`@`から始まる公式LINE ID）または `CONFIG.lineUrl` を設定
   - `lineOaId` があると、LINEのトークに予約メッセージが**自動入力**される
5. `index.html / style.css / app.js` を静的ホスティング（GitHub Pages / Vercel 等）に置く

> `CONFIG.apiUrl` が空のままでも、サイトは**サンプルデータで表示**されるので
> 見た目の確認だけ先にできます。

### サイトの動き

- 上部で「はじめての方／2回目以降の方」を切替（新規対応枠 or 全体枠の空きを表示）
- 日付タブ → 時間グリッドの 〇/△ をタップして **第1・第2希望**を選択（必須）
- 「LINEで予約を送る」で、予約内容のテキストを公式LINEへ送信
- 個人情報（名前・連絡先・来院きっかけ）は公開用シートに出ないのでサイトに漏れない

## 公開（Vercel ※ reserve と同じやり方）

`reserve/` と同様に Vercel で静的サイトとして公開する。サーバー関数は無い
（空き状況は GAS ウェブアプリから取得）ので、ファイルを置くだけで動く。

1. Vercel にログイン → **Add New → Project** → リポジトリ `mochizuki80skip/--mochizuki` を選択
2. **Root Directory** を **`event-reserve`** に設定（重要）
3. Framework Preset：**Other**（Build/Output は空欄でOK）
4. **Deploy**
5. プロジェクト Settings → **Git → Production Branch** を、この作業ブランチ
   （`claude/festive-sagan-2hkas3`）に設定すると、その内容が本番公開される
6. 発行された `https://<project>.vercel.app/` を QR コード化してチラシ等に使える

> デプロイ前に `app.js` の `CONFIG.apiUrl`（GASウェブアプリURL）と
> `CONFIG.lineOaId`／`lineUrl` を設定しておくこと。未設定でもサンプル表示は出る。

### GitHub Pages で公開する場合（代替）

Pages の「Deploy from a branch」はサブフォルダを直接配信できないため、
`event-reserve` の中身を `/docs`（リポジトリ直下）にコピーし、
Settings → Pages → Branch=作業ブランチ / Folder=`/docs` を選ぶ。
