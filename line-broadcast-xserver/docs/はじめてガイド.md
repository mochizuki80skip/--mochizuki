# はじめてガイド：Xserver の設定から使い始めるまで

Xserver にまだ一度もログインしていない状態から、本システムが使えるようになるまでの手順です。
上から順に進めてください。**所要時間の目安：1〜1.5 時間**（SSL の反映待ちを含む）。

> 画面の名前や並びは、Xserver 側の更新で変わることがあります。見つからないときは、近い名前のメニューを探してください。
> 詳しい仕組みや困ったときの対処は `Xserver導入手順書.md` にあります。

## 1. サーバーパネルにログインする

1. ブラウザで Xserver のログインページを開く：https://www.xserver.ne.jp/login_server.php
2. **サーバーID** と **サーバーパネルのパスワード**（控えシート）を入力してログイン
3. 「サーバーパネル」が開けば OK です（以降の手順はすべてここで行います）

> 「Xserverアカウント」（契約・支払い用）とは別の画面です。サーバーパネルには、Xserverアカウントの画面からも入れます（「サーバー管理」→「サーバーパネル」）。

---

## 2. 使うドメインを決める（サブドメインの作成）

### おすすめ：専用のサブドメインを作る

すでにホームページ等で使っているドメインがある場合は、**本システム専用のサブドメイン**を作ると安全です（例：`line.example.com`）。

1. サーバーパネル →「**サブドメイン設定**」
2. 元になるドメインを選び、「サブドメイン設定追加」タブで **サブドメイン名**（例：`line`）を入力 →「確認画面へ進む」→「追加する」
3. 追加後、サーバー上に `/home/サーバーID/line.example.com/public_html/` というフォルダができます

### 独自ドメインがない場合

Xserver が最初から用意している **初期ドメイン**（`サーバーID.xsrv.jp`）でも使えます。
その場合は、フォルダ `/home/サーバーID/サーバーID.xsrv.jp/public_html/` に置きます。**もともと入っている `index.html`（Xserver の案内ページ）があれば削除してください**（残っていると、そちらが先に表示されます）。

> 以降、`line.example.com` を、あなたが使うドメインに読み替えてください。控えシートに記入。

---

## 3. 無料の SSL（https）を設定する

LINE との連携には **https が必須**です。

1. サーバーパネル →「**SSL設定**」
2. 手順 2 のドメインを選び、「独自SSL設定追加」タブ →「確認画面へ進む」→「追加する」
3. 反映まで **数分〜1 時間** かかることがあります（先の手順を進めて構いません）

---

## 4. PHP のバージョンを設定する

1. サーバーパネル →「**PHP Ver.切替**」
2. 手順 2 のドメインを選ぶ
3. **8.2**（8.1 以上ならどれでも可）を選び、「バージョン切替」

---

## 5. データベース（MySQL）を作る

本システムのデータを保存する場所です。

1. サーバーパネル →「**MySQL設定**」→「**MySQL追加**」
   - **MySQLデータベース名**：`linehub` など（実際は `サーバーID_linehub` のように前に付きます）。文字コードは **UTF-8**。→「確認画面へ進む」→「追加する」
2. 「**MySQLユーザ追加**」タブ
   - **MySQLユーザID**：例 `linehub`（実際は `サーバーID_linehub`）
   - **パスワード**：自動生成または自分で設定（**8 文字以上、控えシートに記入**）
   - →「確認画面へ進む」→「追加する」
3. 「**MySQL一覧**」タブ →「アクセス権未所有ユーザ」から、作ったユーザーを **「追加」** してデータベースに紐づける（権限はすべて）
4. 「MySQL設定」画面（または MySQL ホスト名の表示欄）で **MySQL ホスト名**（例：`mysql1234.xserver.jp`）を確認して控える

> 控える4点：**データベース名・ユーザー名・パスワード・MySQL ホスト名**（`localhost` ではない場合があります）。

---

## 6. FTP ソフト（FileZilla）でサーバーに接続する

1. FileZilla をインストールして起動
2. 上部の入力欄に次を入れて「クイック接続」
   - **ホスト**：控えシートの FTP ホスト名（例：`sv1234.xserver.jp`）
   - **ユーザー名**：サーバーID
   - **パスワード**：サーバーパネルのパスワード
   - **ポート**：空欄のまま（または `21`）
3. 「証明書を信頼しますか？」と出たら「OK」（暗号化接続で安全です）
4. **隠しファイルを表示する設定（重要）**：メニュー「サーバー」→「**強制的に隠しファイルも表示**」にチェック
   （`.htaccess` というドットで始まるファイルを送るために必要です）

右側の画面（サーバー側）に `line.example.com` などのフォルダが見えれば接続成功です。

> **FTP ソフトを使わない方法（ファイルマネージャ）**：専用の ZIP `line-broadcast-xserver-filemanager.zip` を使います。
> サーバーパネル →「ファイルマネージャ」で、ドメインのフォルダ（例：`line.example.com`）を開き、この ZIP をアップロード →
> ZIP を選んで「解凍」するだけで、`public_html` と `app` が正しい場所に配置されます（フォルダの移動は不要）。
> 解凍後、`public_html` の中に `.htaccess` と `index.php` があること、`app` が `public_html` と同じ階層にあることを確認してください。
> 確認が終わったら、ZIP ファイル自体はサーバーから削除して構いません。

---

## 7. ファイルをアップロードする

ZIP を展開すると、次のようになっています。

```
line-broadcast-xserver-upload/
 ├─ START-HERE_はじめに.txt
 ├─ upload/
 │   ├─ public_html/   ← ① これの「中身」をアップロード
 │   └─ app/           ← ② これを「フォルダごと」アップロード
 └─ docs/              ← 手順書（アップロード不要）
```

FileZilla の右側（サーバー）で、手順 2 のドメインのフォルダ（例：`/line.example.com/`）を開きます。左側（自分のパソコン）で ZIP を展開した場所を開いて、次のようにドラッグ&ドロップします。

| 左（自分のパソコン） | 右（サーバー）のアップロード先 |
|---|---|
| ① `upload/public_html/` の**中身すべて**（`index.php`・`install.php`・`.htaccess`・`robots.txt`・`assets` フォルダ） | `/line.example.com/public_html/` の中 |
| ② `upload/app/` **フォルダごと** | `/line.example.com/` の直下（`public_html` と**同じ階層**に `app` ができる） |

アップロード後、サーバー側が次のようになっていることを確認します。

```
/line.example.com/
 ├─ public_html/
 │    ├─ .htaccess        ← 見えない場合は手順 6-4 を再確認
 │    ├─ index.php
 │    ├─ install.php
 │    ├─ robots.txt
 │    └─ assets/
 └─ app/
      ├─ bootstrap.php
      ├─ schema.sql
      ├─ cron.php
      ├─ src/  routes/  views/  storage/ …
```

> `docs` フォルダはアップロードしないでください（不要です）。

---

## 8. ブラウザで初期設定（インストーラー）を行う

1. ブラウザで `https://line.example.com/` を開く（SSL の反映前は開けないことがあります。しばらく待ってから）
2. 自動で **セットアップ画面** になります
   - 「動作環境のチェック」がすべて ✔ であることを確認
   - ✘ がある場合は、`Xserver導入手順書.md` のトラブルシューティングを参照
3. 次を入力して「セットアップを実行」
   | 欄 | 入れるもの |
   |---|---|
   | MySQL ホスト名 | 手順 5 で控えたもの |
   | データベース名 / ユーザー名 / パスワード | 手順 5 で控えたもの |
   | 公開URL | `https://line.example.com`（末尾に `/` を付けない） |
   | 管理者のログインID | 例：`admin`（半角英数字 3〜50 文字） |
   | 管理者のパスワード | 8 文字以上 |
4. 「**セットアップが完了しました**」と出たら成功です。
   - **「あなた専用のアクセス用 URL」が表示されます。必ず控えてください**（控えシートに記入）。このURLを開いた端末だけがログイン画面を見られます。
   - `install.php` は自動で削除されます。削除できなかった旨が表示されたら、FileZilla で `install.php` を削除してください。

> 次回以降は、アクセス用 URL を **1 回開いた端末**ならブックマークした `https://line.example.com/` から入れます。別のパソコン・スマホでは、その端末で 1 回アクセス用 URL を開いてください。

---

## 9. 定期実行（Cron）を設定する

予約した配信とステップ配信を、**1 分ごとに自動で送る**ための設定です。これがないと、予約時刻になっても送られません。

1. サーバーパネル →「**Cron設定**」→「Cron設定追加」タブ
2. 次のように入力
   - **分・時・日・月・曜日**：すべて「**毎**」（または `*`）
   - **コマンド**（そのまま貼り付け。サーバーIDとドメインを自分のものに）
     ```
     /usr/bin/php8.2 /home/サーバーID/line.example.com/app/cron.php
     ```
     手順 4 で 8.1 を選んだ場合は `php8.1` にします。
3. 「確認画面へ進む」→「追加する」

---

## 10. 動作を確認する

1. `https://line.example.com/` を開き、管理者のログインIDとパスワードでログイン
2. ダッシュボードに赤い「**定期実行（cron）が動いていません**」が出ていたら、数分待ってから再読み込み。**消えれば Cron は成功**です。消えない場合は手順 9 のコマンド（PHP バージョン、サーバーID、フォルダ名）を見直してください。
3. 次に **LINE 公式アカウントを接続** します → `アカウント接続手順書.md`
   （各店舗のチャネルアクセストークン・チャネルシークレットの取得と、Webhook URL の設定）

## 困ったとき

| 症状 | まず見るところ |
|---|---|
| `https://…` が開けない・保護されていない通信と出る | 手順 3（SSL）の反映待ち。最大 1 時間ほど待つ |
| 404（Not Found）と出る | ① アクセス用 URL（`?k=…` 付き）を開いていない ② `.htaccess` がアップロードされていない（手順 6-4） |
| セットアップ画面で「データベースに接続できません」 | 手順 5 の4点（ホスト名・DB名・ユーザー名・パスワード）。ユーザーを DB に紐づけたか（5-3） |
| セットアップ画面で ✘ がある | `app` フォルダの場所（`public_html` と同じ階層）、書き込み権限（705 または 755） |
| Xserver の案内ページが出る | `public_html` に `index.html` が残っている。削除する |
| そのほか | `Xserver導入手順書.md` の「トラブルシューティング」 |

## 完成後の使い方（かんたんな流れ）

1. 各店舗の LINE 公式アカウントを登録（`アカウント接続手順書.md`）
2. **全店舗 一括配信** で、配信するアカウント・日時・タグ・メッセージを選んで配信
3. 「ステップ配信」で、友だち追加後の自動メッセージを設定
4. スタッフには、各アカウントの「設定」→「担当者」から**ログインID**と**初期パスワード**を発行（その店舗だけ操作可能）
