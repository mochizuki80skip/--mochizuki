# エリア別・社員向けの自動タグ付けガイド

「各エリアの登録用URLから登録した人にエリアのタグを付ける」「社員だけが知る合言葉で、社員のタグを付ける」ための使い方です。
付けたタグは、**一括配信のオーディエンス**や**ステップ配信の開始条件**に使えます。

## 仕組み
LINE は、友だち追加のときに「どのURLから来たか」をシステムに教えてくれません。そこで、次の方法を使います。

1. エリアごとの**登録用URL**を作る（開くと、公式LINEのトーク画面に「静岡エリア」のような**メッセージが入力済み**で開く）
2. お客様が友だち追加して、その入力済みのメッセージを**送信**する
3. システムが、メッセージの内容（キーワード）を見て、**自動でタグを付ける**（お礼の自動返信も送れます）

```
エリア別のチラシ・QR → 登録用URL → 友だち追加 → 「静岡エリア」を送信 → タグ「エリア：静岡」が付く
```

> **注意**：お客様が「送信」を押した人にだけタグが付きます。押さなかった人には付きません。
> 本番の前に、実際のスマホで必ず動きを確認してください（LINE の画面の動作は、端末や LINE のバージョンで違うことがあります）。

## 設定の手順（エリア別）
1. システムの左メニュー「**自動タグ付け**」を開く
2. 「ルールを追加」に入力する

   | 欄 | 入力例 |
   |---|---|
   | キーワード | `静岡エリア` |
   | 一致のさせ方 | 完全に一致したとき（おすすめ） |
   | 付けるタグ | 「＋新しいタグを作る」→ `エリア：静岡` |
   | 自動返信（任意） | `静岡エリアで登録しました。ありがとうございます！` |

3. 「ルールを追加」を押す
4. 一覧の「**URLをコピー**」または「**QRコード**」から、登録用のURLとQRを取り出す
   - URL：SNS・LINE・メール・Webサイトに載せる
   - QRコード：「画像を保存」して、チラシやポスターに載せる
5. エリアの数だけ、1〜4を繰り返す（例：静岡・浜松・沼津・島田…）

## 社員向けの設定（合言葉）
1. 「自動タグ付け」で、次のルールを追加する

   | 欄 | 入力例 |
   |---|---|
   | キーワード | 社員だけが知る**長めの合言葉**（例：`Staff-8x3k-2026`） |
   | 一致のさせ方 | 完全に一致したとき |
   | 付けるタグ | `社員` |
   | 自動返信 | `社員登録が完了しました`（任意） |

2. 社員には、**合言葉をトークで送ってもらう**よう伝える（LINE公式アカウントを友だち追加 → 合言葉を送信）
3. 合言葉は、**推測されにくい**ものにしてください。短い言葉や、よくある単語だと、社員以外が偶然送ってしまうおそれがあります。
4. 合言葉が漏れたとき・退職者が出たときは、ルールを**削除**して、新しい合言葉のルールを作り直します。

> 社員専用の「URL」だけでは、URLを知った社外の人も登録できてしまいます。合言葉を併用すると、社員だけにタグが付きます。
> 社員専用のQR・URLも、「自動タグ付け」の登録用URLとして作れます（キーワードに合言葉を入れます）。ただし、URLに合言葉が含まれるため、**社内にだけ共有**してください。

## タグを使った配信
- **エリア別のキャンペーン**：「全店舗 一括配信」→ オーディエンスで「エリア：静岡」を選ぶ
- **社員向けの連絡**：オーディエンスで「社員」を選ぶ
- **登録後の自動メッセージ**：「ステップ配信」で、トリガーを「タグが付いたとき」にして `エリア：静岡` を選ぶと、登録した直後・翌日・1週間後…と、自動で順番に送れる

## すでに友だちの人にも使える
すでに友だちになっているお客様も、登録用URLを開いて「送信」すれば、タグが付きます（URLを開くとトーク画面にキーワードが入力済みで開くため）。キャンペーンのお知らせで、URLをタップしてもらう形にもできます。

## キーワードの判定ルール
- 全角・半角、大文字・小文字、余分な空白の違いは、同じものとして扱います（例：「静岡エリア」「 静岡ｴﾘｱ 」は一致）。
- **完全一致**：メッセージ全体がキーワードと同じときだけ反応します（おすすめ）。
- **含む**：メッセージの中にキーワードが入っていれば反応します（2文字以上のキーワードのみ）。
- 1つのメッセージに複数のルールが一致したら、すべてのタグが付きます。
- ルールは「停止」で一時的に止められます。

## 困ったとき
| 症状 | 確認すること |
|---|---|
| 登録用URLが作れない（「LINE に接続できません」） | アクセストークンが正しいか（アカウントの「設定」）。Webhook の設定ができているか |
| URLを開いてもメッセージが入力済みにならない | スマホの LINE を最新にする。別の端末でも試す。うまくいかないときは、お客様に「キーワード（例：静岡エリア）をそのまま送ってください」と案内する |
| 送信してもタグが付かない | Webhook がオンで「検証」が成功しているか。ルールが「有効」か。キーワードの綴りが一致しているか |
| タグが付いたのに、自動返信が来ない | 自動返信の欄が空でないか。LINE側の仕様で、返信の有効期限（約1分）を過ぎると送れません |
