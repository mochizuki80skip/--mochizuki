# 2つ目のシステムの設置手順（80SKIPグループの公式LINE用）

接骨院用とは**別のシステム**として、80SKIPグループの公式LINEを管理する、2つ目のシステムを設置します。
データ・ログイン・画面がすべて分かれるので、接骨院のお客様に80SKIPの内容が誤って届くことを防げます。

> 中身は、接骨院用と同じ ZIP（`line-broadcast-xserver-subdomain.zip`）を使います。作業は「サブドメイン → DB → アップロード → 初期設定 → Cron → LINE接続」の順で、1つ目と同じです。

## 作るもの（接骨院用との対応）
| 項目 | 接骨院用（設置済み） | 80SKIPグループ用（今回作る） |
|---|---|---|
| サブドメイン | `sekkotsuline.hachimaru-80skip.com` | 例：`group.hachimaru-80skip.com`（好きな名前でOK） |
| データベース | `main80skip_sline` | 例：`main80skip_group`（別に作る） |
| システム名 | 接骨院 LINE 一括配信 | 例：80SKIPグループ LINE 配信 |
| 管理者のログインID・パスワード | 接骨院用 | **別のもの**を決める |
| アクセス用URL | 接骨院用 | **別のもの**が自動で作られる |
| Cron | 設定済み | **もう1つ追加**する |

## 手順

### 1. サブドメインを作る
1. サーバーパネル →「ドメイン」→「サブドメイン設定」
2. サブドメイン名（例：`group`）を入れて追加
3. 「SSL設定」で、新しいサブドメインに無料独自SSLを追加
4. 「PHP」→「PHP Ver.切替」で、**8.2** に設定

### 2. データベースを作る
1. 「データベース」→「MySQL設定」→「MySQL追加」：データベース名 `group` など（実際は `main80skip_group`）、文字コードは UTF-8
2. 「MySQLユーザ追加」：ユーザー `group`、**新しいパスワード**
3. 「MySQL一覧」で、**ユーザーをデータベースに紐づける**
4. データベース名・ユーザー名・パスワードを控える（MySQLホスト名は `localhost`）

### 3. ファイルをアップロードする
1. ファイルマネージャで、`hachimaru-80skip.com` → `public_html` → **新しいサブドメインのフォルダ**（例：`group.hachimaru-80skip.com`）を開く
2. 最初から入っている `index.html` と `default_page.png` を**削除**する
3. `line-broadcast-xserver-subdomain.zip` をアップロードして「展開」する
4. `index.php`、`install.php`、`robots.txt`、`.htaccess`、`assets`、`app` が揃っているか確認し、ZIPを削除する

### 4. 初期設定（ブラウザ）
1. `https://group.hachimaru-80skip.com/` を開く（自動でセットアップ画面になる）
2. 次を入力して「セットアップを実行」

   | 欄 | 入力 |
   |---|---|
   | MySQL ホスト名 | `localhost` |
   | データベース名・ユーザー名・パスワード | 手順2のもの |
   | **システム名** | `80SKIPグループ LINE 配信` |
   | 公開URL | `https://group.hachimaru-80skip.com` |
   | 管理者のログインID・パスワード | **接骨院用とは別のもの** |

3. 完了画面の**アクセス用URL**を控える

### 5. Cron を追加する
サーバーパネルの「Cron設定」で、**もう1件追加**します（接骨院用の設定は消さない）。

- 分・時・日・月・曜日：すべて `*`
- コマンド：
  `/usr/bin/php8.2 /home/main80skip/hachimaru-80skip.com/public_html/group.hachimaru-80skip.com/app/cron.php > /dev/null 2>&1`

数分後、システムの赤い警告（定期実行が動いていません）が消えれば成功です。

### 6. LINE公式アカウントを接続する
手順は、これまでの「LINE公式アカウントの接続手順」と同じです。80SKIPグループの公式LINEで行います。

1. 公式アカウントマネージャー →「設定」→「Messaging API」→「Messaging APIを利用する」
2. **プロバイダー**を選ぶ：80SKIPグループとして管理するプロバイダーを選びます（接骨院のプロバイダー「なつめ接骨院グループ」とは**別**にします）。すでに80SKIPグループのプロバイダーがあればそれを、なければ新しく作ります。
3. LINE Developers で、**チャネルシークレット**と**チャネルアクセストークン（長期）**を取得（スクリーンショットなどに写さない）
4. システムの「LINE アカウント追加」に入力して追加
5. 追加後の「設定」画面の **Webhook URL** を、公式アカウントマネージャー（または LINE Developers）の Webhook URL に貼って保存
6. 「応答設定」で **Webhook をオン**にして、LINE Developers で「検証」が成功することを確認

### 7. エリア別・社員向けの自動タグ付けを設定する
[エリア別・社員向け自動タグ付けガイド](エリア別・社員向け自動タグ付けガイド.md) に従って、次を設定します。

1. エリアごとのルール（キーワード → エリアのタグ）を作り、登録用URL・QRコードを取り出す
2. 社員用の合言葉のルールを作る
3. 自分のスマホで、URLを開いて「送信」し、タグが付くことを確認する

## 使い始めたあと
- **エリア別のキャンペーン**：「全店舗 一括配信」で、オーディエンスにエリアのタグを選んで配信
- **社員向けの連絡**：オーディエンスに「社員」のタグを選んで配信
- **配信数の上限**：LINE公式アカウントの料金プランごとの月間メッセージ数に注意（タグで絞った分だけ消費します）
- バックアップ、アップデートは、接骨院用と同じです（`app/config.php` と `app/storage/` は上書きしない）

## 接骨院用システムの更新
今回の機能追加（自動タグ付け）は、接骨院用のシステムにも入ります。接骨院用は、新しい ZIP を同じ場所に**上書きして展開**してください（`app/config.php` と `app/storage/` は ZIP に含まれていないので、そのままです）。データベースは、画面を開くと**自動で更新**されます。
