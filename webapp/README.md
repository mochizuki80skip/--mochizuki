# ONE'S BODY 静岡安倍川店 体験会 予約サイト（Google Apps Script）

今の予約表スプレッドシートをそのまま読み書きする、Webの予約フォームです。
無料・Googleアカウント内で完結し、公開すると予約用URLが1本発行されます。

## できること
- 予約表（8/28・29・30タブ）から空き状況を計算して **◎△×** を表示
  - 各時間で「**新規対応=✅ のルーム**」のうち **氏名が空いている数** を集計
  - **2〜4枠 → ◎**／**1枠 → △**／**0枠（満員）→ ×**
- お客様から **①予約者名 ②電話番号 ③メールアドレス ④予約のきっかけ**（設定タブC2以下）を取得
- 予約が入ると、空いているルームへ自動で書き込み＋「**Web予約**」タブへ全項目（メール含む）を記録

## 導入手順（初回のみ・5分ほど）
1. 予約表のスプレッドシートを開く
2. メニュー **拡張機能 → Apps Script** を開く
3. 最初からある `Code.gs` の中身を全部消し、本フォルダの **`Code.gs`** の内容を貼り付け
4. 左の **＋ → HTML** を選び、ファイル名を **`Index`**（拡張子不要）にして作成 →
   本フォルダの **`Index.html`** の内容を貼り付け
5. フロッピー（保存）アイコンで保存
6. 右上 **デプロイ → 新しいデプロイ**
   - 種類（歯車）＝ **ウェブアプリ**
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**（＝お客様が誰でも予約できる）
   - **デプロイ** を押す
7. 初回は権限の承認を求められます → 自分のGoogleアカウントで承認
8. 表示された **ウェブアプリのURL** が予約サイトです。お客様へ共有してください

## 運用メモ
- **予約を受け付ける枠は、予約表で「新規対応」に✅を入れた枠だけ** です。
  担当がいない・休憩などで受けられない枠は✅を外すと、サイト上で満員（×）扱いになります。
- 予約が入ると氏名は予約表に書き込まれ、「体験者一覧」タブや「設定」タブの集計にも自動反映されます。
- 予約の全記録（メールアドレス含む）は「Web予約」タブに残ります（初回予約時に自動作成）。
- **担当者（対応者）欄は空のまま**書き込みます。スタッフが後から割り当ててください。

## コードを修正したとき（再公開）
`Code.gs` / `Index.html` を編集したら、**デプロイ → デプロイを管理 → 対象を編集（鉛筆）→ バージョン＝新バージョン → デプロイ**。
※ URLは変わりません。

## 変更したい場合の主な箇所（Code.gs 上部）
- `DAYS`：対象の日付タブ名とラベル
- `ROOMS`：ルームの列位置（今の予約表に合わせて設定済み）
- ◎△×の判定：`getAvailability_()` 内の `open >= 2` などの数値
