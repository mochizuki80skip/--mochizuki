# 体験会 予約サイト（1枚のWebページ版 / アプリ不要）

接骨院サイトと同じ「静的ページ＋公式LINE受け渡し」方式です。

- 空き状況（◎△×）は **公開したスプレッドシートから自動読み込み**（読み取りのみ）
- 予約データは**保存しません**。入力内容を整えて、**公式LINEに送信直前の状態**でお客様へ渡します（お客様が送信）
- 判定：各時間で「新規対応=✅ のルームのうち氏名が空いている数」→ **2〜4=◎ / 1=△ / 0=×**

## ファイル
- `reservation.html` … 予約サイト本体 → **`index.html` にリネームして設置**
- `privacy.html` … プライバシーポリシーページ（`index.html` と同じ場所に一緒に置く）
- `reservation_body.html` / `privacy_body.html` … それぞれの中身（Artifactプレビュー用）

> 2ファイル（`index.html` と `privacy.html`）を同じフォルダに入れて一緒にアップロードしてください。
> 予約ページの「プライバシーポリシー」リンクから `privacy.html` が開きます（Netlifyでは `/privacy` で表示）。
> 電話番号を正式決定後に変える場合は `privacy.html` 内の `090-3252-0772`（コメント目印あり）を差し替えてください。

## 使う前に2か所だけ設定
`reservation.html` を開き、上部の `CONFIG` を編集します。

1. **公式LINEのID**（必須）
   ```js
   lineId: "@000abcde",  // ← 公式LINEのID（@から始まるID）に書き換え
   ```
   LINE公式アカウントの「友だち追加」→ ベーシックID（例：`@onesbody`）を入れてください。

2. **スプレッドシートの共有**（自動読み込みに必要）
   スプレッドシートを開き、右上「共有」→「リンクを知っている全員」を **閲覧者** に設定。
   （`spreadsheetId` は現在のシートに設定済みです）

※ きっかけの選択肢は `channels:` を編集すれば変更できます（設定タブと合わせてください）。

3. **プライバシーポリシー**
   別ページ `privacy.html` として用意済みです（運営事業者・電話番号は記入済み／同意チェックは任意）。
   予約ページの本文と最下部からリンクで開けます。
   ※ 規定文はテンプレートです。実運用前に内容をご確認ください（必要に応じて専門家へご相談を推奨）。

## 公開（お客様に配る）方法の例
`reservation.html` はどこに置いても動きます。手軽な順に：

- **Netlify Drop**（最速）：`reservation.html` を **`index.html` にリネーム**してから
  https://app.netlify.com/drop にドラッグ → 発行URLがそのまま予約サイトに。
  （サイトを保持・独自名にするには無料アカウントでログインしてください。ファイル名が `index.html` だとトップURLで開けます）
- **GitHub Pages / Cloudflare Pages** 等の静的ホスティングにアップロード
- 既存のホームページ内に設置

> 補足：スプレッドシートの自動読み込みは、ホスティングした状態（http/https）で動作します。
> Artifactプレビューやローカルの二重ダウンロードでは読み込めず、サンプル表示になる場合があります。

## 運用の要点
- サイトで予約できる枠＝**予約表で「新規対応」に✅を入れた枠**です（担当不在・休憩は✅を外す→自動で×表示）。
- 予約表に氏名が入ると空きが減り、◎△×が自動で更新されます（ページ再読み込みで最新化）。
- 予約内容はLINEに届くだけなので、担当者が予約表へ記入して確定してください。

## 動作の流れ
体験日を選ぶ → 時間（◎△△…）を選ぶ → お名前・電話・メール・きっかけを入力 →
「入力内容を確認する」→ 確認パネル →「LINEを開いて送信する」でお客様がLINE送信。
