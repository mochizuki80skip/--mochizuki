# なつめ接骨院 静岡長田店 チャリティー施術会 予約サイト（8/28〜30）

島田市店（`event-reserve`）と同型の予約サイト。お客様が空き状況（〇△×）を見て、
第1〜第3希望・氏名・電話・きっかけ・区分を選び、**公式LINEに予約文を送信**する。
予約確定はLINEでの最終確認をもって行う（サイト側にログは残さない）。

## 構成

```
【予約表スプレッドシート】8/28・8/29・8/30 タブ（14ベッド/15分/区分/新規対応☑）
   ├─ build-osada-sheet.gs          … 予約表を自動生成（初回のみ実行）
   └─ availability-aggregator-osada.gs … 予約表を読み取り 空き〇△× を JSON 配信（doGet）
        │  ← サイトがアクセスするたびに最新シートを読む（常時読み取り＝自動最新化）
        ▼
【サイト】index.html / app.js / style.css / privacy.html
   日付タブ × 時間グリッドで〇△×表示 → 第1〜3希望を選んでLINE送信
```

- **はじめて（初診/30分）** … 新規対応☑ベッドで「その時刻＋次の15分」が空きの数
- **2回目以降（15分）** … 新規対応☑ベッドで「その時刻」が空きの数
- 区分=「初」は30分＝縦2枠として埋まり判定（手動で縦2行を結合する運用と一致）

## セットアップ

### 1. 集計GASを公開（空き状況の自動読み取り）
1. 予約表スプレッドシートで **拡張機能 → Apps Script**
2. `availability-aggregator-osada.gs` を新規ファイルとして貼り付け保存
   （`build-osada-sheet.gs` と同じプロジェクトでOK。補助関数は `a_` 始まりで衝突しない）
3. **デプロイ → 新しいデプロイ → 種類「ウェブアプリ」**、アクセス「**全員**」で発行
4. 発行URLを `app.js` の `CONFIG.apiUrl` に貼り付け

### 2. サイト設定（`app.js` の CONFIG）
- `apiUrl` … 上で発行した集計GASのURL（空だとサンプル表示）
- `lineOaId` … 公式LINE ID（`@881udugq`）
- `refreshMinutes` … 自動再取得の間隔（既定10分）

### 3. 公開（静的ホスティング）
`event-reserve` と同様に Vercel / Cloudflare 等へ静的サイトとして配置（サーバー関数不要）。
Root Directory を `osada-reserve` に設定してデプロイ。発行URLをQRコード化して集客に使える。

> `apiUrl` 未設定でもサイトはサンプルデータで表示されるので、見た目確認だけ先に可能。
