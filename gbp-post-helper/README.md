# GBP 投稿アシスタント（接骨院向け Chrome 拡張機能）

Google ビジネスプロフィール（GBP）の「最新情報」投稿を、**最終確認の手前まで**自動化します。
投稿ボタンは拡張機能からは押しません（誤投稿防止のため、必ず人が確認して押す）。

## できること

1. **投稿文の作成**
   - テーマ（季節のケア / 症状解説 / セルフケア / スポーツ / 交通事故 / お知らせ / キャンペーン / スタッフ紹介）を選ぶ
   - 「テンプレートで作成」… 月ごとの季節の話題を入れた定型文（AI 不要・無料）
   - 「AIで作成」… Gemini API で院の情報・時期・メモから文章を生成
2. **広告規制チェック**（入力中に自動）
   - 「治る」「完治」「必ず」「No.1」「体験談」「ビフォーアフター」、本文中の電話番号（GBP で却下されやすい）などを検出
   - 肩こり×保険、誇大表現、割引表示などは注意として表示
   - 設定で院独自の NG ワードを追加可能
   - ※ 簡易チェックです。最終判断は人が行ってください
3. **GBP の投稿画面に自動入力**
   - 本文を入力し、画像を選んでいれば添付も試みる
   - 入力欄が見つからないときは本文をクリップボードにコピー（貼り付けるだけで OK）
4. **下書き管理**
   - 投稿予定日つきで保存、「投稿済み」管理。まとめて作っておき、当日は開いて入力するだけ

## インストール（ストア公開なし・自分の PC で使う）

1. このフォルダ（`gbp-post-helper`）を PC にダウンロード
2. Chrome で `chrome://extensions` を開く
3. 右上の「デベロッパー モード」をオン
4. 「パッケージ化されていない拡張機能を読み込む」→ `gbp-post-helper` フォルダを選択
5. ツールバーのパズルアイコンからピン留めしておくと便利

## 使い方

1. 拡張機能アイコンを押すとサイドパネルが開く → 「設定」で院名・地域・締めの定型文を保存
   （AI を使う場合は [Google AI Studio](https://aistudio.google.com/apikey) で API キーを取得して登録）
2. 「作成」タブでテーマを選び、テンプレート or AI で本文を作成 → チェック結果を見て修正
3. 「GBP の投稿画面を開く」→ GBP で **「最新情報を追加」（投稿作成画面）を開いた状態**にする
4. サイドパネルの「GBP に入力」を押す → 本文（と画像）が入る
5. GBP 画面でボタン（予約・電話など）を選び、内容を確認して **自分で「投稿」を押す**

## 注意・制限

- GBP の画面構成は Google がたびたび変更します。入力欄が見つからなくなった場合はクリップボードコピーで対応できます
- ボタン種別（予約 / 今すぐ電話 等）の選択は画面で行ってください
- API キー・下書きはこの PC の Chrome 内にのみ保存されます
- 完全自動化（予約投稿）が必要になった場合は、Google Business Profile API（利用申請が必要）での実装を検討
